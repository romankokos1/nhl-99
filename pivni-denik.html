Sdílení s partou

Aby vám žebříček fungoval společně, potřebujete jednu databázi zdarma. Založí ji jeden z vás a ostatní pozve odkazem.

  1. Založ účet na supabase.com → New project.
  2. V SQL Editoru spusť tento skript:
create table piva ( id text primary key, osoba text not null, nazev text not null, pivovar text, styl text, abv text, kde text, datum text, poznamka text, hodnoceni int, foto text, vytvoreno timestamptz default now() ); alter table piva enable row level security; grant select, insert, update, delete on public.piva to anon; create policy "cist" on piva for select using (true); create policy "pridat" on piva for insert with check (true); create policy "upravit" on piva for update using (true); create policy "mazat" on piva for delete using (true); -- fotky: úložiště obrázků insert into storage.buckets (id, name, public) values ('fotky','fotky',true) on conflict (id) do nothing; create policy "fotky cist" on storage.objects for select using (bucket_id = 'fotky'); create policy "fotky pridat" on storage.objects for insert with check (bucket_id = 'fotky'); create policy "fotky mazat" on storage.objects for delete using (bucket_id = 'fotky'); -- mista: sdílené polohy podniků na mapě create table mista ( klic text primary key, nazev text, lat double precision, lng double precision, upraveno timestamptz default now() ); alter table mista enable row level security; grant select, insert, update, delete on public.mista to anon; create policy "mista cist" on mista for select using (true); create policy "mista pridat" on mista for insert with check (true); create policy "mista upravit" on mista for update using (true); create policy "mista mazat" on mista for delete using (true); -- pivovary: sdílený seznam pivovarů (kanonický název, poloha, info) create table pivovary ( klic text primary key, nazev text not null, mesto text, web text, rok_zalozeni int, popis text, lat double precision, lng double precision, upraveno timestamptz default now() ); alter table pivovary enable row level security; grant select, insert, update, delete on public.pivovary to anon; create policy "pivovary cist" on pivovary for select using (true); create policy "pivovary pridat" on pivovary for insert with check (true); create policy "pivovary upravit" on pivovary for update using (true); create policy "pivovary mazat" on pivovary for delete using (true); -- liky: lajky na jednotlivé zápisy piv create table liky ( pivo_id text not null, osoba text not null, vytvoreno timestamptz default now(), primary key (pivo_id, osoba) ); alter table liky enable row level security; grant select, insert, update, delete on public.liky to anon; create policy "liky cist" on liky for select using (true); create policy "liky pridat" on liky for insert with check (true); create policy "liky mazat" on liky for delete using (true);
  1. V Settings → Data API zkopíruj Project URL a publishable klíč.

Máš už tabulku z dřívějška? Spusť jen to, co ti chybí: pro fotky alter table piva add column if not exists foto text; + blok od komentáře „fotky"; pro mapu blok od „mista"; pro pivovary blok od „pivovary"; pro lajky blok od „liky".

Do prohlížeče patří jen publishable/anon klíč — je bezpečné ho sdílet. Nikdy sem nedávej secret / service_role klíč.
