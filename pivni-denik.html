Jak ti mám říkat?

Toto jméno se objeví u tvých piv v žebříčku party. Ulož si ho — zůstane v tomhle prohlížeči.

Nastavení sdílení (Supabase)

Aby vám žebříček fungoval společně, potřebujete jednu databázi zdarma. Založí ji jeden z vás a ostatním pošle stejnou appku i klíče.

  1. Založ si účet na supabase.com → New project (zdarma).
  2. V projektu otevři SQL Editor a spusť tento skript (vytvoří tabulku a povolí zápis):
create table piva ( id text primary key, osoba text not null, nazev text not null, pivovar text, styl text, abv text, kde text, datum text, poznamka text, hodnoceni int, vytvoreno timestamptz default now() ); alter table piva enable row level security; create policy "vsichni cist" on piva for select using (true); create policy "vsichni pridat" on piva for insert with check (true); create policy "vsichni upravit" on piva for update using (true); create policy "vsichni mazat" on piva for delete using (true);
  1. V Settings → API (nebo Connect) zkopíruj Project URL a publishable (nebo anon) klíč.

Tento klíč je určený do prohlížeče — je bezpečné ho sdílet s kamarády. Nikdy sem nedávej service_role / secret klíč.
