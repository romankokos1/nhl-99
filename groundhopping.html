Jak ti mám říkat?

Tvoje jméno se objeví u tvých návštěv v žebříčku party. Zůstane uložené v tomto zařízení.

Sdílení s partou

Aby vám žebříček fungoval společně, potřebujete jednu databázi zdarma. Založí ji jeden z vás a ostatní pozve odkazem.

  1. Založ účet na supabase.com → New project.
  2. V SQL Editoru spusť tento skript:
create table navstevy ( id text primary key, osoba text not null, domaci text not null, hoste text, skore_d int, skore_h int, soutez text, stadion text, mesto text, zeme text, datum text, divaku int, poznamka text, hodnoceni int, foto text, vytvoreno timestamptz default now() ); alter table navstevy enable row level security; grant select, insert, update, delete on public.navstevy to anon; create policy "cist" on navstevy for select using (true); create policy "pridat" on navstevy for insert with check (true); create policy "upravit" on navstevy for update using (true); create policy "mazat" on navstevy for delete using (true); insert into storage.buckets (id, name, public) values ('fotky','fotky',true) on conflict (id) do nothing; create policy "fotky cist" on storage.objects for select using (bucket_id = 'fotky'); create policy "fotky pridat" on storage.objects for insert with check (bucket_id = 'fotky'); create policy "fotky mazat" on storage.objects for delete using (bucket_id = 'fotky'); create table stadiony ( klic text primary key, nazev text, mesto text, zeme text, klub text, kapacita int, lat double precision, lng double precision, upraveno timestamptz default now() ); alter table stadiony enable row level security; grant select, insert, update, delete on public.stadiony to anon; create policy "stadiony cist" on stadiony for select using (true); create policy "stadiony pridat" on stadiony for insert with check (true); create policy "stadiony upravit" on stadiony for update using (true); create table liky ( navstevy_id text not null, osoba text not null, vytvoreno timestamptz default now(), primary key (navstevy_id, osoba) ); alter table liky enable row level security; grant select, insert, update, delete on public.liky to anon; create policy "liky cist" on liky for select using (true); create policy "liky pridat" on liky for insert with check (true); create policy "liky mazat" on liky for delete using (true); create table komentare ( id text primary key, navstevy_id text not null, osoba text not null, text text not null, vytvoreno timestamptz default now() ); alter table komentare enable row level security; grant select, insert, update, delete on public.komentare to anon; create policy "komentare cist" on komentare for select using (true); create policy "komentare pridat" on komentare for insert with check (true); create policy "komentare mazat" on komentare for delete using (true);
  1. V Settings → Data API zkopíruj Project URL a publishable klíč.

Do prohlížeče patří jen publishable/anon klíč — je bezpečné ho sdílet. Nikdy sem nedávej secret / service_role klíč.

Pozvi kamarády

Pošli jim tenhle odkaz. Když ho otevřou, appka se sama připojí k vaší databázi — nic neopisují. Zadají jen svoje jméno.
