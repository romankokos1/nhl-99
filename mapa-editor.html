⚙ Nastavení Firebase

Pro sdílení mezi počítači potřebuješ bezplatný Firebase projekt.
Vytvoř si ho na console.firebase.google.com a vyplň tyto údaje:

▸ Jak najít tyto údaje? (klik)

Jdi na console.firebase.google.com → klikni Přidat projekt → zadej název → pokračuj

V levém menu vyber Build → Realtime Database → klikni Create Database → vyber region → v pravidlech nastav ".read": true, ".write": true

Klikni na ikonu ⚙ vedle Project Overview → Project settings → dolů na Your apps → klikni </> → zkopíruj firebaseConfig

📂 Načíst data hráčů

Vlož obsah proměnné const SAMPLES = [...] nebo jen pole [{...}].
Data se uloží do Firebase a budou dostupná všem uživatelům.
