⚙ Nastavení Firebase projektu

Tyto údaje se uloží pouze v tomto prohlížeči. Na stránce jsou vidět jen po přihlášení se správnými hesly.

▸ Jak to nastavit (klik pro návod)

Jdi na console.firebase.google.com → Add project → pojmenuj → pokračuj

Vlevo: Build → Authentication → Get started → záložka Sign-in method → povol Email/Password

V záložce Users → Add user → přidej e-mail a heslo pro každého uživatele (jen ty dva)

Vlevo: Build → Realtime Database → Create Database → region Europe → v záložce Rules vlož:
{"rules":{".read":"auth != null",".write":"auth != null"}}

Ikona ⚙ vedle názvu projektu → Project settings → klikni </> → pojmenuj app → zkopíruj hodnoty z firebaseConfig
