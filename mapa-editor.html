⚙ Nastavení Firebase projektu

Vyplň údaje ze svého Firebase projektu. Uloží se pouze v tomto prohlížeči.

▸ Jak to nastavit (klik)

console.firebase.google.com → Add project → pojmenuj → pokračuj

Vlevo: Build → Authentication → Get started → Sign-in method → povol Email/Password

Authentication → záložka Users → Add user → přidej e-mail + heslo pro každého uživatele zvlášť

Vlevo: Build → Realtime Database → Create Database → region Europe → záložka Rules → vlož a publikuj:
{"rules":{".read":"auth != null",".write":"auth != null"}}

⚙ vedle názvu projektu → Project settings → Your apps → </> → zkopíruj hodnoty z firebaseConfig
